## Compile and run one question

Open a terminal in this folder and run (replace the filename as needed):

```powershell
g++ -std=c++17 -Wall -Wextra -pedantic Q01_Prime_Number.cpp -o Q01.exe
.\Q01.exe
```

Compile each `.cpp` file separately because each file contains its own `main()` function.
